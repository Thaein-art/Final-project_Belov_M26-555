# Final-project_Belov_M26-555

Учебное приложение для регистрации пользователей, управления виртуальными валютными портфелями, покупки и продажи валют и получения обменных курсов.

Проект состоит из двух логических частей:

- Core Service — пользователи, портфели, кошельки и операции;
- Parser Service — получение курсов из CoinGecko и ExchangeRate-API,
  обновление кеша и сохранение истории.
